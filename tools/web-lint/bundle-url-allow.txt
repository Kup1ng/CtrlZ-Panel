# URL strings that scripts/check-web-bundle.mjs (spec 3.5) accepts in the built apps. One line, one
# reason; a line without " # reason" is an error. A string that is not here fails CI until someone
# has read where it comes from. The grammar is in the script's header:
#
#   url  <string>... [in <path part>] # reason    exact strings; `in` limits them to paths containing that part
#   host <name>...                    # reason    a documentation host, for files under node_modules/ inside .next/standalone only, and
#                                                   never for a link to a file that a program loads (a script, an image, a release asset)
#
# Nothing here is a destination the app connects to. The proof of that is the offline run of 17.4
# (spec 3.5), where every container is on a closed network and the guard of 17.2 fails any request.
