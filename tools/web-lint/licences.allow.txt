#   type <SPDX id>        a licence type that may appear. An SPDX expression such as "A AND B" or

#   package <name>        a package that may appear whatever its licence says: the name as pnpm
#                         prints it, or a prefix ending in "*".

# changed to one that is not listed, fails the step until someone has read it and added a line here.
