# Provenance

One row per source file, checked by `scripts/build.mjs`: the build fails if a file under `svg/` or `brand/` has no row, or a row has no file (spec 7.3, T-476).

Every icon under `svg/` was drawn from scratch for Ctrl Z, on a 24 grid with a 1.5px round stroke. No Control D file was opened, traced or used as a reference while drawing (D13). Names, metaphors and geometry are ours; the metaphors (a shield, a magnet, a die, a folder) are common to every icon set.
